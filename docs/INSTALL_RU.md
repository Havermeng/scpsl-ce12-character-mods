# Установка и удаление

1. Нужен компилирующийся исходный проект CE 12.0.2 с его обычными зависимостями, Unity 6000.3 LTS и Built-in RP.
2. Сохраните копию проекта, остановите Play и дождитесь компиляции.
3. Старый 3114 1.x удалите его старым менеджером с восстановлением оригиналов. Только затем убирайте старый менеджер.
4. Импортируйте полностью пакет 939, 3114 или оба. При первом импорте применяются компоненты по умолчанию.
5. Откройте SCP → Mods → Character Mod Manager. У каждого мода свои компоненты и Apply/Uninstall. При конфликте окно показывает путь и причину.

## Удалить один мод

Нажмите Uninstall у нужного мода. Подождите компиляции. Второй мод сохраняется. После этого можно нажать Remove installer files у удалённого мода. Для повторной установки используйте Install, если установщик оставлен, либо импортируйте пакет заново.

## Удалить всё

Удалите оба мода через Uninstall, дождитесь компиляции и удалите оба неактивных установщика через менеджер. Оставшуюся папку Assets/ScpCeModManager можно удалить через Project в Unity; общая Assets/ScpCeMods после удаления установщиков пуста. Резервные копии ScpCeModBackups можно архивировать/удалить только после успешного удаления всех модов и проверки проекта. Scp3114ModBackups относятся к старому менеджеру 1.x.

## Если что-то мешает

- **Edited after install:** сохраните свои правки отдельно и верните ожидаемые файлы перед сменой состава. Не удаляйте журнал/резервные копии ради обхода проверки.
- **Source differs / GUID conflict:** проект отличается от поддержанной CE 12.0.2 либо содержит ручной перенос. Операция останавливается до замены файлов.
- **Interrupted transaction:** остановите Play/компиляцию, нажмите Recover. Сначала проверяются резервные копии, затем восстанавливается состояние до операции.
- **Нет меню / ошибки C#:** проверьте Console и дождитесь импорта. Менеджер компилируется отдельной Editor-сборкой; ошибки базового проекта исправляются отдельно.
- **Нет новых классов у клиента:** те же моды/компоненты должны быть установлены и собраны у сервера и клиентов.

Console: префикс [SCP CE12 Mods]. Состояние: ProjectSettings/ScpCeModsState.json. Незавершённая операция: ProjectSettings/ScpCeModsTransaction.json. Резервные копии и завершённые операции: ScpCeModBackups. Build callback копирует Translations рядом с EXE; сохраняйте менеджер, пока мод установлен.
