# SCP:SL CE12 — SCP-939 & SCP-3114

[English](README_EN.md) · [Установка и удаление](docs/INSTALL_RU.md) · [Компоненты](docs/COMPONENTS.md) · [Проверки](docs/VALIDATION.md)

**Статус: Preview.** Свежий импорт в Unity, компиляция/Mirror weaving, независимое удаление и 68 проверок механик на локальном хосте пройдены. Отдельный EXE и удалённый клиент для этой версии не проверены; замечания журнала указаны в [VALIDATION](docs/VALIDATION.md).

Два отдельных Unity-мода для **SCP:SL Community Edition 12.0.2**:

- **SCP-939** — наша одетая 939, поглаживания, объятия, прогулки за руку, подарки с передачей предмета, свидания и ужин, реплики и симпатия.
- **SCP-3114** — скелет с маскировкой, атаками, удушением, интерфейсом и анимациями; дополнительная готическая горничная и необязательный спавн в раунде.

Каждый мод устанавливается своим .unitypackage. Можно поставить один или оба, включать и отключать компоненты, редактировать установленные исходники и полностью удалить мод через менеджер. Порядок установки не важен; удаление одного сохраняет второй.

## Быстрый старт

1. Сохраните резервную копию проекта, остановите Play.
2. Выберите **Assets → Import Package → Custom Package…** и импортируйте пакет полностью.
3. Дождитесь установки и компиляции. Откройте **SCP → Mods → Character Mod Manager**.
4. Измените компоненты и нажмите **Применить / Apply**.
5. Для удаления нажмите **Удалить мод / Uninstall**, дождитесь компиляции, затем при желании удалите его установочные файлы кнопкой в том же окне.

Если раньше ставили SCP-3114 Mod Manager 1.0/1.1, **сначала удалите установленную им версию через старый менеджер**, затем импортируйте новый пакет. Не удаляйте старые резервные копии до восстановления исходников. Ручной перенос поверх уже изменённого проекта автоматически не перезаписывается.

## Использование

В Remote Admin:

    forcerole <ID игрока> Scp939Dressed
    forcerole <ID игрока> Scp3114
    forcerole <ID игрока> Scp3114Dressed

У 939 подойдите к персонажу и нажмите взаимодействие (обычно **E**). Меню: колесо мыши / стрелки, E или Enter для выбора, Backspace назад. **939 help** показывает команды взаимодействий.

У 3114: основная атака — удар, удержание взаимодействия над подходящим трупом — маскировка, удержание перезарядки (обычно R) — снять маскировку, вторичная атака после раскрытия — удушение. **F1** открывает помощь. Переназначенные клавиши сохраняются.

Спавн 3114 в обычном раунде по умолчанию выключен. Две одетые роли доступны через администратора. У сервера и клиентов должны совпадать версии модов и выбранные компоненты.

## Исходники

Установленные C#-файлы можно редактировать. Перед следующей сменой компонентов или удалением менеджер обнаруживает ручные изменения и останавливает конфликтную операцию: сначала сохраните свои изменения отдельно и восстановите ожидаемые файлы. Ваша правка не стирается молча.

Sources/Manager содержит менеджер, Sources/Content — добавляемые файлы и патчи интеграции. Для сборки пакетов из репозитория: **python tools/build_packages.py**, Python 3.10+. Для обычной установки Python и Git не нужны.

Моды не меняют сцены, освещение, графику, аккаунты, Steam/Central или сеть Windows. Они не делают базовый проект автономным: его собственные требования сохраняются. Отдельные киносценарии, строительный режим, новые человеческие классы и фреймворк думми в пакеты не включены. Если соответствующая интеграция уже установлена, 939 может использовать её через необязательный адаптер.

Готовые голосовые записи 939 не включены: карточка использованного ранее голоса не указывает лицензию. Компонент озвучки поддерживает ваши WAV в **Assets/StreamingAssets/Scp939Voice/custom/<ключ>.wav**; ключи — в Scp939Lines.cs. По умолчанию остаются субтитры без голоса.
